

# BCS-554 HTML & CSS Development Lab

This repository contains my **HTML & CSS Development Lab practical assignments** completed as part of the B.Tech Computer Science and Engineering (CSE), 5th Semester curriculum.

The practical file includes 15 experiments with their aims, theories, algorithms, source code, inputs, outputs, results, and viva-voce questions.


## 🎯 Objectives

- Understand the fundamentals of HTML.
- Learn CSS styling and web page design.
- Create structured and attractive web pages.
- Understand HTML elements, attributes, and forms.
- Practice CSS layouts and styling techniques.
- Develop basic front-end development skills.

## 🛠️ Technologies Used

- **HTML5** – Structure of web pages.
- **CSS3** – Styling and page layouts.
- **VS Code** – Code editor.
- **Web Browser** – Running and testing HTML pages.

9. Result
10. Viva-Voce Questions


## 🚀 How to Use

1. Clone this repository:
   ```
   git clone https://github.com/YOUR-USERNAME/BCS-554-HTML-CSS-Lab.git
   ```
2. Open the downloaded folder.
3. Open the PDF file to view the practical assignments.
4. To practice the programs, write the HTML and CSS code in VS Code.
5. Run the HTML files in any modern web browser.
